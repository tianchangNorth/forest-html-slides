# 设计规范

从参考 HTML 的实际样式提取。优先保留整体气质与可读性，不为凑固定数字牺牲内容。

## 色彩

| 语义 | CSS token | 色值 | 使用方式 |
| --- | --- | --- | --- |
| 纸面 | `--paper` | `#f3f3e9` | 主要浅色页面 |
| 墨色 | `--ink` | `#153f35` | 浅色页标题与正文 |
| 次要文字 | `--muted` | `#69766d` | 说明、标识、页脚 |
| 分隔线 | `--line` | `#d6dcd0` | 表格、分区与图示连接 |
| 森林绿 | `--green` | `#286850` | 浅色页强调、图表与滑块 |
| 青柠 | `--lime` | `#d0f477` | 深色页重点、结果与主要按钮 |
| 深色背景 | `--dark` | `#123e33` | 封面、转折、重点交互、收束 |
| 陶土橙 | `--orange` | `#c3663e` | 少量差异或焦点提示 |

深色页覆写：正文 `#f1f4e5`、次要文字 `#adc3b1`、线条 `#476557`。外围舞台背景 `#e1e4da`，导航背景 `#edf0e5`。不要在深色背景直接使用浅色页的暗绿强调字。

## 字体与比例

使用系统字体，避免为了风格下载网络字体：

```css
--sans: Inter, "PingFang SC", "Microsoft YaHei", system-ui, sans-serif;
--mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

| 元素 | 桌面基准 | 特征 |
| --- | --- | --- |
| 封面标题 | 76 px / 1.16 | 600 字重，负字距，通常两行 |
| 页标题 | 46 px / 1.25 | 600 字重，短而具体 |
| 分区标题 | 25–31 px | 500–550 字重 |
| 引导句 | 22 px / 1.65 | 次要色，通常一两行 |
| 主体 | 19–24 px / 1.6–1.7 | 便于投屏阅读 |
| 大数字 | 71–84 px | 数字等宽，单位相对较小 |
| 代码 | 17–20 px / 1.56–1.75 | 精简到必要行数 |
| 短标识 | 13–14 px | 等宽英文或页序，有限使用 |
| 页脚 | 12 px | 仅来源、假设、必要边界 |

中文大标题不要密集换行，也不要填满宽度。正文溢出时先删重复内容、缩短句子或拆页，再微调字号。

## 空间与构图

- 桌面画布 1440 × 810，按可用视口等比缩放。底部导航独立于幻灯片，约 72 px 高。
- 幻灯片内边距：上 53、左右 72、下 50 px；主体与标题区相距约 31 px；页脚距底部 21 px。
- 双栏间距约 64–85 px。封面可用 1.12:1 的不对称双栏，右侧放一个与主题有关的核心过程或结果。
- 主体优先用平面双栏、水平流程、细线列表、简洁表格、大数字和可编辑解释图。
- 只有代码、真实交互控件或需明确界定的结果区才使用浅色背景块。按钮圆角约 3–4 px。
- 深色页是节奏点，不强制页码位置或固定占比。原稿的深色页承担封面、协作流程、费用交互与收束。
- 图示需要可读标签、合理阅读方向和足够连接线留白。不增加没有信息作用的装饰形状。

## 版式选择

| 要表达的关系 | 推荐版式 / 已有类 |
| --- | --- |
| 开场主张与一个实例 | `.hero-grid`、`.hero-diagram` |
| 两种方法、观点或产物 | `.grid2`、`.split-lane` |
| 输入、机制、输出 | `.pipeline`、`.node`、`.arrow` |
| 各维度逐项比较 | `.compare`，语义化 `table` |
| 代码与解释对应 | `.api-layout`、`.annotation`、`.code` |
| 改变参数后观察结果 | `.slider-row`、`.bar-row`、`.route-result` |
| 同一机制的不同场景 | `.segmented` 或 `.use-nav` |
| 核心指标及测量条件 | `.metrics`、`.metric-caveat` |
| 能力边界与风险 | `.limit-grid`、`.limit-item` |
| 收束与职责划分 | `.takeaway`、`.role` |

类名中的历史词汇只是样式组件名，不要求沿用原稿主题。

## 移动端与动态效果

700 px 以下改为单栏文档流，左右约 25 px 留白；标题约 31 px、封面约 48 px、主体约 17–20 px。页面可纵向滚动，导航固定底部并给正文留出空间。复杂比较表可缩减列或改成逐项排列，不能依赖页面横向溢出。

参考转场约 350 ms，淡入并垂直位移 9 px。数值、柱形过渡约 250–500 ms。核心演示由观众触发，并提供重置或重播。`prefers-reduced-motion: reduce` 时直接显示可理解状态，不依赖动画完成事件计算结果。

## 表达方式

标题直指主题或可靠结论；正文使用具体动词、真实输入与明确输出。避免宣传口号、空洞三段排比、整页缩略词堆积和每页固定三个卡片。需要影响观众判断的边界留在页内，更长解释放备注。
